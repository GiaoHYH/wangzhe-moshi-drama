## 本剧爆款结构说明

### 黄金钩子原则（已落实到每一集）
- **前3秒法则**：每集开场即冲突/悬念，无铺垫废镜头
- **集尾强钩**：每集结尾必留"下一秒会发生什么"式悬念（见分集大纲"结尾钩子"栏）
- **爆点节奏公式**：每集1个反转 · 每3集1个爆点 · 每10集1个季级高潮（第10/20/30集）

### 三层反转结构（全剧主骨架）
1. **事件层反转**：复活甲是废技能 → 是可无限复活的战略级技能
2. **动机层反转**：贺九霄要的是陆沉的命 → 他要的是陆家血脉的"门"
3. **价值层反转**：贤者的庇护是复活技能 → 本质是"封印深渊之门的门锁"，陆沉自己就是"门"

### 情绪曲线设计
爽感（逆袭/反杀）× 虐感（妹妹被俘/战友牺牲/未婚妻"死而复生"）交替推进，
每3集一个情绪峰值，确保观众"上瘾式追剧"。
